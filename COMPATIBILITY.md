# Проверка 0.2.47-dev

Статически проверены пять APK из apks.rar: ColorOS 17.3.9 China и 17.3.12 Global,
Realme UI 16.6.13 China, OxygenOS 16.6.20 и 17.5.4. Дополнительно переданные
Launcher Cn.apk и System Launcher_17.5.4OXYGEN17.apk побайтово совпали с последним.
Это проверка API и исходников, а не подтверждение работы на всех прошивках.
Чужие лаунчеры на телефон не устанавливались.

## Изменения 0.2.47

- Регистрация wallpaper callback выбирается отдельно от отписки: именованные
  addBlurBitmapListener/release либо проверенная пара a/c с release=b.
  Неизвестный или неоднозначный API не вызывается.
- Recorder снимка выбирается по имени семейства и полной статической сигнатуре
  Runnable,int,int,CompletableFuture,View; суффикс lambda больше не зафиксирован.
- Обычные drawBackground(Canvas), (Canvas,View) и (Canvas,CellLayout) отделены от
  ConvertBgParams по типам. Контекст отрисовки очищается после вызова.
- В 16.x контур строится теми же вызовами OplusPath/IconUtils, что в лаунчере.
  В 17.x сохраняется штатный метод SmoothRoundedManager.
- Для изменения размера папки 17.x использует свой toConvertBgBounds, а 16.x —
  проверенную формулу с усечением координат и зеркалированием при RTL+resize.
  При неготовом материале обычная подложка рисуется напрямую: штатный blur-путь
  не умеет рисовать наш Drawable и иначе мог оставить пустой фон.
- Split Flux определяется по типам полей и drawSubLayerInternal, а не по версии
  16.6.8. Обработка применяется только к плоской подложке с живым вторым слоем;
  сложные изображения сохраняют обычную обработку.
- Ошибка одного необязательного обработчика или установки хука не прерывает
  установку остальных. В лог записываются версия лаунчера, API, версия модуля,
  выбранные пути и ошибки недоступных API.

Предыдущие исправления 0.2.45/0.2.46 сохранены: кэш GPU-слоя дока, привязка ширины
к движению иконок, фиксированная ширина при выключенной автодлине, окраска shortcut-кнопок, раздельный
CPU-кэш одинаковых иконок и обновление размеров GPU-сэмплера при повороте.

## Ограничения

Новый док Android 16 не включён: штатный фон установлен на другом контейнере.
В OxygenOS 17.5.4 нет LauncherWallpaperManager, но фабрика захвата найдена через
MaterialBlurAnimHelper.mStaticWallpaperBlurFactory. Работа этого OEM backend
на устройстве пока не подтверждена. Отказ неизвестного API оставляет запасной
путь; это не означает поддержку любой версии лаунчера.

## Проверка на устройстве

1. Frosted/Liquid; наследуемые/собственные настройки; GPU вкл./выкл.
2. Статичные/живые обои, смена обоев, покой после разблокировки.
3. Drag дока и отмена, одна/несколько иконок, выключенная автодлина, drawer.
4. Папки 1x2/2x1: создание, hover, изменение размера, запуск/возврат, RTL.
5. Часы, календарь, shortcut-кнопки, split Flux, смена палитры и отключение модуля.
6. Одинаковая иконка в разных местах; поворот/изменение разрешения.

Если эффект не работает, нужны версия прошивки/лаунчера, шаги и экспорт логов
CherryPick/LSPosed. На телефоне в этой работе ничего не устанавливалось и не
перезапускалось, настройки/данные не менялись. Для обновления используется
исходный ключ подписи автора; keystore в исходники не включается.
